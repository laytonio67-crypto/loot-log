SEASON BACKGROUND IMAGES
========================
Drop a .jpg file into this folder using the exact filename below for whichever
seasons you want to have a real picture background on the Seasons tab.

Recommended size: roughly 800x450 (16:9) or larger — it gets cropped to fill
the card, so a wider/taller image just gets center-cropped, no distortion.

Any season you DON'T add a file for just keeps the current gradient look —
nothing breaks, nothing looks broken, you can add them gradually.
